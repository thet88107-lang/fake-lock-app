# Fake Lock — قفل وهمي للموبايل (أندرويد)

تطبيق برانك بسيط: بيعرض شاشة قفل وهمية فوق أي تطبيق تاني، وبترجع تظهر تاني لحظة ما حد يفتح الشاشة بزرار الباور — فعليًا الزرار بيطفي/يفتح الشاشة زي العادي (ده مش ممكن تتحكم فيه من غير روت)، لكن اللي هيبان للي بيستخدم الموبايل إنه "رجع لنفس شاشة القفل" كل مرة.

## المميزات
- شاشة قفل بتقليد شكل شاشة القفل الحقيقية (ساعة + تاريخ)
- بترجع تظهر تلقائي أول ما الشاشة تتفتح (SCREEN_ON) حتى بعد ريستارت
- PIN اختياري تحدده انت عشان تقفل الشاشة، أو تسيبه فاضي ويبقى مجرد "دوس في أي حتة"
- تقدر توقفها في أي وقت من التطبيق نفسه

## إزاي تاخد ملف APK جاهز (أسهل طريقة — من غير أي تثبيت على جهازك)
المشروع فيه ملف `.github/workflows/build-apk.yml` بيخلي GitHub يبني الـ APK لوحده أونلاين. كل اللي عليك:

1. اعمل حساب على [github.com](https://github.com) لو مش عندك.
2. اعمل **repository جديد فاضي** (New repository) — سيبه Public أو Private براحتك.
3. ارفع عليه محتويات المجلد ده (أسهل طريقة: من صفحة الريبو دوس "uploading an existing file" واسحب كل الملفات والمجلدات، أو لو عارف Git: `git init && git add . && git commit -m "init" && git remote add origin <رابط الريبو> && git push -u origin main`).
4. روح تبويب **Actions** في الريبو، هتلاقي الـ workflow "Build APK" شغّال لوحده (أو دوس Run workflow لو ملوش بادئ).
5. لما يخلص (علامة ✅ خضرا)، دوس عليه وانزل لحد **Artifacts**، هتلاقي ملف اسمه `FakeLock-debug-apk` — نزّله، فكّه هتلاقي `app-debug.apk`.
6. انقل الـ APK ده لموبايلك (واتساب لنفسك، درايف، كابل...) وافتحه — هيطلب منك تسمح بـ "تثبيت من مصادر غير معروفة"، وافق، وثبّت عادي.

## إزاي تبنيه بنفسك (بديل) من Android Studio
1. نزّل **Android Studio** (مجاني).
2. افتح المجلد ده (`FakeLock`) كـ Open Project.
3. سيبه يعمل Gradle Sync (هيحمل الـ dependencies لوحده أول مرة، محتاج نت).
4. وصّل موبايلك بالـ USB (فعّل Developer Options + USB Debugging)، أو استخدم Emulator.
5. دوس Run ▶️.

أو لو عايز APK من غير كابل: من Android Studio
`Build > Build Bundle(s)/APK(s) > Build APK(s)` وهتلاقي ملف الـ APK في
`app/build/outputs/apk/debug/`.

## إزاي تستخدمه
1. افتح التطبيق، دوس **"اديني صلاحية الظهور فوق التطبيقات"** ووافق في الشاشة اللي هتفتح.
2. (اختياري) اكتب PIN لو عايز قفل فعلي.
3. دوس **"شغّل القفل الوهمي"**.
4. من دلوقتي، أي حد يفتح الموبايل (حتى بزرار الباور) هيلاقي شاشة القفل الوهمية.
5. **عشان توقفه**: افتح تطبيق Fake Lock تاني من الـ app drawer ودوس "إيقاف" — أو لو حطيت PIN، دوس على شاشة القفل واكتب الـ PIN ودوس "فتح".

## حدود مهمة (قانونية وتقنية)
- ده شغال بس على الموبايل بتاعك انت ونفسك — متستخدموش على موبايل حد تاني من غير إذنه، ده ممكن يعتبر تعدي.
- مفيش API في أندرويد يقدر "يعطّل" زرار الباور فعليًا من غير روت/Device Owner، فالتطبيق بيستخدم حيلة إنه يرجع يظهر فورًا بعد أي فتح شاشة.
- بعض أجهزة أندرويد (خصوصًا Xiaomi / Huawei / Samsung بعض الإصدارات) بتحتاج منك تفعّل يدويًا "Autostart" أو "Battery optimization: Don't optimize" للتطبيق عشان الـ Service يفضل شغال في الخلفية.
- لو نسيت الـ PIN وقفلت نفسك، اتحكم من: Settings > Apps > Fake Lock > Force Stop (أو Uninstall) لإنهاء الخدمة فورًا.
